# AI usage

## Tool used

OpenAI Codex assisted with this third-year computer science final project inside the project workspace.

## What AI helped with

- Reviewed the project proposal, mockup, design guidance, and supplied assets.
- Helped implement and adjust the Flutter welcome, login, registration, conversation-list, and settings screens.
- Helped write widget-flow checks and 390 × 844 screenshot references.
- Helped review privacy and repository setup, and draft this README and the security checklist.

## Student review and learning

The student chose the project scope and supplied the design and brand assets. The student should read the route setup in `lib/main.dart`, follow each screen under `lib/screens/`, and run `flutter test` to understand how the demo flow is checked. Before presenting or publishing, compare every screen against the Figma mockup and verify all remaining security-checklist items.

AI assistance has not implemented a real account server, chat backend, nearby connection, or compass. The current forms and service-like interactions remain a prototype and should not be presented as production security or messaging.
